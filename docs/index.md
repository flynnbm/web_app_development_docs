# Web App Development

Practical notes for building web applications with HTML, CSS, JavaScript, and
Python. This collection grows as features are built and explained, with small
guides that can be reused in future projects.

## What is a web app?

A **web application** includes the browser interface and the server components
that support it:

- **Frontend:** HTML defines page elements, CSS controls their appearance and
  layout, and JavaScript adds browser behavior such as reacting to clicks.
- **Backend:** Server code, such as Python with Flask, handles requests, performs
  application logic, and accesses data.
- **Database:** Stores information that the backend can retrieve or update.

**Full-stack web development** means working across the frontend and backend.
“Website” and “web app” overlap; “web app” often emphasizes interactive tasks
such as searching, filtering, and editing information.

## How these guides will be organized

Use task-based titles so it is easy to find an answer to “How do I do this?”
The following are planned topics, to be added as we work through them:

- **HTML and page structure:** Add a button, group elements, and place a section
  above a results heading.
- **CSS and layout:** Style a button, adjust spacing, align elements, and handle
  smaller screens.
- **JavaScript and interaction:** Handle a click, update page content, and show
  or hide controls.
- **Python and backend:** Add a Flask route, accept request parameters, and
  return data to the browser.
- **Complete features:** Connect a button to a filter and refresh search results.

A guide can explain a small technique on its own, then link to a complete
feature showing how the pieces interact.
